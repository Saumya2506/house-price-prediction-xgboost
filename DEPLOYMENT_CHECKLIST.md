# Deployment checklist

- [ ] Put the original Ames `train.csv` in `data/train.csv`.
- [ ] Run `python train_model.py`.
- [ ] Confirm `models/house_price_model.pkl` exists.
- [ ] Confirm `models/metrics.json` exists.
- [ ] Run `streamlit run app.py`.
- [ ] Test at least 5 different property inputs.
- [ ] Create a public GitHub repository.
- [ ] Push the complete project.
- [ ] Deploy `app.py` on Streamlit Community Cloud.
- [ ] Open the public URL in an incognito window.
- [ ] Copy the live URL into the internship response only after verifying it works.
